## Milestone 3 Progress Summary:

Milestone 3 focused on implementing one major new feature and deploying the full application to Railway. Our team selected the Budgeting Module as the new feature, designed to help users understand and manage their finances using the 50/30/20 budgeting model. The module categorizes expenses into Needs, Wants, and Savings and compares the user’s actual spending against recommended percentages. This feature enhances the application by giving users clearer insight into their financial habits. To support this, both the frontend and backend were updated with new logic, UI components, and data handling. The team also prepared the application for public deployment by configuring production settings and environment variables. The project was successfully deployed on Railway, allowing users to access the application through a public URL. The README was updated to include deployment information and instructions for running the app locally. Weekly stand up meetings in Weeks 13, 14, and 15 helped track progress, assign responsibilities, and address blockers. Overall, Milestone 3 strengthened the project by adding meaningful functionality and making the application fully deployable.
